# feature-impl Skill

TDD Feature Implementation Workflow with GitHub Integration

## Quick Start

### Trigger the Skill

Natural language triggers:
```
"Start stripe-integration feature"
"Continue toss-integration"
"Resume payment-feature"
"Toss 시작"
"Stripe 이어서"
```

### Requirements Check

The skill will automatically verify:
- ✅ Git repository exists
- ✅ Git remote configured (CRITICAL!)
- ✅ GitHub CLI (`gh`) installed
- ✅ GitHub authenticated

**If any check fails, the skill exits with helpful error messages.**

### What the Skill Does

1. **Analyzes your techspec** (`docs/features/{feature}/techspec.md`)
2. **Maps tasks to specialized agents** (frontend, backend, database, etc.)
3. **Creates GitHub Issues** for all tasks
4. **Launches agents in parallel** (60% time savings!)
5. **Enforces TDD** (Red-Green-Refactor for every task)
6. **Tracks progress** via TODO.md + GitHub Issues
7. **Syncs state** automatically

### File Structure Created

```
docs/features/{feature}/
├── techspec.md      # INPUT (you provide this)
├── plan.md          # Generated by skill
└── TODO.md          # Generated & auto-synced

.git/branches/
└── feature/{feature}  # Work branch

GitHub Issues:
└── Created automatically with TDD workflow
```

### Techspec File Recognition

The skill supports flexible techspec naming:

**Priority 1: User-mentioned file**
```
"docs/my-spec.md를 techspec으로 써줘"
"/Users/jax/Desktop/spec.pdf 사용"
```

**Priority 2: Standard location** (case-insensitive)
```
docs/features/{feature}/
  techspec.md
  TechSpec.md
  tech-spec.md
  tech_spec.md
  spec.md
```

**Priority 3: Auto-search**
```
Searches entire docs/ directory
Asks to copy to standard location
```

**Priority 4: Prompt to create**
```
Suggests: /workflows:tech-spec
```

### Parallel Execution

The skill launches multiple specialized agents simultaneously:

```
Phase 1: Foundation (3 tasks in parallel)
├── Agent 1: devops-infrastructure-specialist
├── Agent 2: database-engineer-specialist
└── Agent 3: test-engineer-specialist

⏱️ Sequential: 90 min
⏱️ Parallel: 30 min
💾 Savings: 67%
```

### TDD Enforcement

Every task follows:
1. 🔴 **RED**: Write failing tests (25% time)
2. 🟢 **GREEN**: Minimal implementation (50% time)
3. 🔵 **REFACTOR**: Improve code (25% time)

Each step gets its own commit.

### Progress Tracking

**Dual Tracking System**:
- **TODO.md**: Fast local view, human-readable checklist
- **GitHub Issues**: Source of truth, always authoritative

**Automatic Sync**:
- Before showing status
- After completing phase
- Before skill exit

**Mismatch Resolution**:
- GitHub Issues = source of truth
- TODO.md updated automatically

### Agent Types

The skill maps tasks to these specialists:

| Agent | Expertise |
|-------|-----------|
| `backend-api-specialist` | REST/GraphQL APIs, server logic |
| `frontend-ui-specialist` | React components, UI/UX |
| `frontend-state-specialist` | State management, data fetching |
| `database-engineer-specialist` | Schema, types, data models |
| `devops-infrastructure-specialist` | Setup, CI/CD, deployment |
| `test-engineer-specialist` | Test infrastructure, QA |
| `security-engineer-specialist` | Security audits, auth |
| `frontend-performance-specialist` | Performance optimization |

**Mapping is done automatically** by analyzing:
- File paths in techspec
- Keywords in task descriptions
- Techspec section structure

### Troubleshooting

Common issues and solutions:

**Git remote not configured**
```
❌ This skill requires GitHub integration
→ git remote add origin <url>
```

**Techspec not found**
```
❌ No techspec found
→ Run: /workflows:tech-spec
→ Or place at: docs/features/{feature}/techspec.md
```

**Sync mismatch**
```
⚠️ TODO.md out of sync with GitHub
→ Auto-fixed (GitHub is source of truth)
```

**Build failures**
```
❌ npm run build failed
→ [Fix automatically] [Review code] [Skip]
```
